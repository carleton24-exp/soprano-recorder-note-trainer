# Soprano Recorder Visual Flashcards

An Android flashcard and ear-training app for learning soprano recorder notes, fingerings, and pitch recognition, built with a `WebView` frontend (`app/src/main/assets/index.html`) and `MainActivity`.

## Features
- **Deck 1: Staff → Note**: Identify treble clef notes (including ledger lines and accidentals in Hard mode).
- **Deck 2: Fingering → Note**: Practice baroque soprano recorder fingerings (including half-covered holes and pinched thumb notes in Hard mode).
- **Deck 3: Ear Training**: Listen to synthesized note pitches via Web Audio, replay tones with **Play Note Again**, and identify notes by ear.
- **Study Tools**: Hard mode toggle, deck shuffle, light/dark theme toggle, hints, streak tracking, and clean button-state resets on card transitions.

## Installation
1. Go to the **Releases** section on GitHub.
2. Download the latest APK asset (e.g., `recorder.flash.v2.0.0.apk`).
3. Open the APK on your Android device (allow installing from unknown sources if prompted).
